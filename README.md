# JARVIS v2.0 — голосовой ИИ-ассистент (Android)

Тема: Blue / Cyan / Deep Navy, неоново-стеклянный стиль. Kotlin + Jetpack Compose.

## Структура

- `Персонажи` — 6 персонажей, у каждого свой TTS-голос (высота/скорость) и реакции.
  - FREE: JARVIS, NEO, LUNA, ATLAS
  - VIP: **KENT / BRO**, **SPECTRE VIP** — окно разблокировки с промо-ключом
- `Помощник` — анимированная сфера (пульсация, орбита, реакция на микрофон и эмоции),
  кнопка микрофона, лента диалога, блок «Тест меню удаления приложений» (реальные
  приложения, удаление через `Intent.ACTION_DELETE` с эмоциональной реакцией).
- `Эффекты` — верхний слой: снег / дождь / ёлка / убрать; тумблеры SFX, TTS,
  «Смотреть на экран», «Реакция на крик».

## Логика без заглушек

- **VIP**: окно с вводом промо-ключа. Бета-ключ: `JARVIS-VIP-2026`.
  Статус разблокировки сохраняется в SharedPreferences (`Prefs`).
- **Звуки**: процедурные тона через AudioTrack (без ресурсов) — клик, открытие,
  удаление, удивление, разблокировка.
- **TTS**: `android.speech.tts.TextToSpeech` (русская локаль), pitch/rate каждого персонажа.
- **Крик**: MicMonitor читает PCM через AudioRecord, RMS→дБ; при > −16 дБ (с паузой 3 с)
  персонаж реагирует — если включён «Реакция на крик».
- **Смотреть на экран**: при открытии меню удаления ассистент удивляется и комментирует;
  при удалении — расстраивается (меняется эмоция сферы, текст и скорость речи).

## Разрешения

- RECORD_AUDIO — запрашивается при запуске и при нажатии микрофона.
- SYSTEM_ALERT_WINDOW — заявлено в манифесте для будущего оверлея.

## Сборка APK

### Вариант 1 — Android Studio (рекомендуется)
1. Установите Android Studio Hedgehog (2023.1.1) или новее, SDK 34.
2. `File → Open` → выберите папку `JARVIS20`.
3. Дождитесь Gradle Sync (первый раз потребуется интернет).
4. Debug APK: `Build → Build App Bundle(s)/APK(s) → Build APK(s)`.
   Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.
5. Release APK: `Build → Generate Signed App Bundle/APK → APK`,
   создайте keystore (или выберите существующий), далее `release`.
   Либо `./gradlew assembleRelease`.

### Вариант 2 — командная строка
```bash
cd JARVIS20
# debug (подписан автоматически ключом отладки)
./gradlew assembleDebug
# release (требует signingConfig; проще через мастер в Android Studio)
./gradlew assembleRelease
```
Если Gradle wrapper отсутствует, выполните `gradle wrapper` при установленном
Gradle 8.7+, либо откройте проект в Android Studio — она создаст wrapper сама.

### Установка на устройство
1. Скопируйте APK на телефон.
2. Разрешите «Установка из неизвестных источников» для браузера/файлового менеджера.
3. Установите, запустите, выдайте разрешение на микрофон.

## Промо-ключ (бета)
`JARVIS-VIP-2026` — открывает KENT / BRO и SPECTRE VIP на вкладке «Персонажи».
